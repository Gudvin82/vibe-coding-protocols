# Examples

These examples are synthetic walkthroughs.

They are:
- not real customer projects;
- not production-ready starter repos;
- not claims about real deployments;
- sanitized and safe to study publicly.

Use them as playbooks for how the toolkit can look inside a project.

## Included example folders

- [`todo-app-starter/`](./todo-app-starter/) — Product Brief to first safe slice
- [`telegram-bot-hardening/`](./telegram-bot-hardening/) — bot hardening findings and backlog
- [`landing-page-light/`](./landing-page-light/) — light route for a simple public site
- [`saas-backend-full/`](./saas-backend-full/) — full hardening for a backend-heavy service

Legacy single-file examples remain in this folder for quick reading, but the folder examples are better walkthroughs.
