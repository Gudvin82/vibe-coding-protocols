# Example: before / after Product Brief

## Плохо

> Сделай сервис записи клиентов.

Слишком мало контекста:
- непонятно, для кого;
- непонятно, web это или bot;
- нет active/deferred boundaries;
- нет auth/payment/integration assumptions.

## Лучше

- MVP для записи клиентов на консультации
- active surfaces: web frontend, backend/API, database
- deferred: mobile app, payments, admin analytics
- first outcome: пользователь оставляет заявку и получает подтверждение
- risks: нет Product Brief, нет PROJECT_MAP, legal/payment later
