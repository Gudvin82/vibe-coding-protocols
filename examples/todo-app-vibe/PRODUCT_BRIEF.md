# PRODUCT_BRIEF

## Project

Small collaborative todo app.

## Goal

Ship a first useful slice quickly without turning a simple app into an overengineered platform.

## Active surfaces

- web UI
- backend/API
- database

## Deferred surfaces

- native mobile app
- payments
- admin panel
- AI assistant features

## Expected data

- users
- tasks
- task completion state
- basic timestamps

## First safe vertical slice

- create task
- list tasks
- mark task complete

## Risks to revisit later

- auth boundaries
- role model
- mobile layout
- background reminders
- dependency scanning
