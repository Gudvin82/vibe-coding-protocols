# PRODUCT_BRIEF

## Project

A simple shared todo app for a small team.

## Goal

Ship a first working slice where a user can create, complete and list tasks.

## Active surfaces

- web UI
- backend/API
- database

## Deferred surfaces

- mobile app
- payments
- admin panel
- AI assistant features

## Data notes

- tasks
- users
- task completion status

## First safe vertical slice

- create task
- list tasks
- mark task as done

## Risks to revisit later

- auth hardening
- row-level permissions
- background reminders
- exports and analytics
