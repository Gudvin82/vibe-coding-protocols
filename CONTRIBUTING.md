# Contributing

Улучшения приветствуются.

## Principles

- не добавляйте реальные secrets;
- не добавляйте private project data;
- анонимизируйте examples;
- избегайте tool-specific lock-in без явной причины;
- сохраняйте методологию vendor-neutral;
- если используете внешние идеи или обсуждения, добавляйте attribution;
- не копируйте чужие prompts / skills / frameworks verbatim без разрешения.

## Preferred contribution types

- clearer wording;
- better checklists;
- safer default templates;
- repo structure improvements;
- typo / link fixes;
- new vendor-neutral examples.

## Before opening a PR

Проверьте:
- нет ли лишних локальных путей;
- нет ли customer names;
- нет ли secret-looking placeholders, которые выглядят как реальные ключи;
- не предлагает ли текст risky/destructive action without approval.
