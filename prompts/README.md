# Prompts

Each prompt is a separate markdown file so you can:
- open it quickly;
- copy it as-is;
- adapt it for a project;
- save the final version in `docs/PROMPTS.md` of a real project.

If the AI IDE cannot open links, paste the required prompt blocks manually.
