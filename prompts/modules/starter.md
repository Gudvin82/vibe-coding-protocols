# Starter Module

Use this when the project is new and code should not start before the route is clear.

Ask for:
- product goal;
- first measurable outcome;
- active and deferred surfaces;
- runtime, deploy and data boundaries;
- first safe vertical slice;
- what must stay out of scope for now.

Return:
- a small implementation plan;
- files to create first;
- risks that should move to Hardening.
