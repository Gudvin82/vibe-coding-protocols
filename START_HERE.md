# Start Here

Not sure where to start? Use this file as the canonical route chooser.

Answer 5 questions to choose your route.

## 1. Do you already have code?

- No, only an idea -> Product Brief + Starter Protocol
- Yes, AI-generated code exists -> Light Hardening
- Yes, production or client-facing code exists -> Full Hardening + Security Operations

## 2. Is the project public or private?

- Private or local -> Core path
- Public internet -> Extended path + Perimeter Security Checklist
- Client, paid or production -> Extended path + Security Operations Baseline

## 3. Does it use external APIs, packages or repositories?

- No -> Starter or Hardening basics
- Yes -> Third-Party Registry + Safe Update Workflow

## 4. Does it handle users, payments, personal data or auth?

- Yes -> Full Hardening + legal, payment and security checks
- No -> Light or Standard Hardening may be enough

## 5. Are you working with an AI IDE?

- Yes -> copy `templates/AGENTS.md` or an IDE-specific template such as `templates/AGENTS.claude.md`, `templates/AGENTS.cursor.md` or `templates/AGENTS.windsurf.md`
- No -> use the protocols and checklists manually

## Notes

- Use the `Core` path when the project is still private, local or MVP-stage.
- Use the `Extended` path when the project is public, monetized, client-facing or production-bound.
- `vibe-check` is a readiness signal, not a security certification.
