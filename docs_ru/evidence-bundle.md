
# Evidence Bundle

Evidence Bundle — это переносимый proof-пакет, который можно дать:
- ревьюеру;
- техлиду;
- клиенту;
- внешнему evaluator;
- AI-агенту;
- команде перед PR/release.

Он собирает route recommendation, trust-check summary, proof counts,
proof snapshot, risk register, PR gate и next actions в один пакет.
