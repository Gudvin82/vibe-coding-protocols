# Лицензия

Repository package: `v0.8.9`

VCP использует dual-license модель, чтобы кодовые поверхности было проще внедрять, а методологические материалы сохраняли понятные требования к attribution.

## Лицензия на код

Код, CLI, scripts, tests, CI examples и executable examples лицензируются по MIT.

Это покрывает:
- `vcp_cli/`
- `scripts/`
- `tests/`
- `ci-examples/`
- `setup.py`
- wrapper/package metadata

## Лицензия на docs и methodology

Документация, methodology, diagrams, presentations, checklists и narrative case-study материалы остаются под CC BY 4.0.

Это покрывает:
- `README.md` и `README_ru.md`
- `docs/`
- `docs_ru/`
- `protocols/`
- преимущественно методологические `templates/`
- `assets/diagrams/`
- `assets/presentations/`
- `case-studies/`

## Зачем dual license

- MIT снижает friction для code/CLI adoption.
- CC BY 4.0 сохраняет требования к attribution для methodology и teaching materials.
- Репозиторий честно разделяет reusable code и reusable guidance.

## Что можно делать

По MIT для кода:
- копировать, модифицировать, встраивать и перераспределять кодовые поверхности;
- использовать CLI и scripts в коммерческих сценариях.

По CC BY 4.0 для docs/methodology:
- копировать и адаптировать методологию с attribution;
- переводить, remix и republish материалы с понятным credit.

## Attribution expectations

Для reuse методологии/docs:
- указывайте Vibe Coding Protocols;
- оставляйте ссылку на репозиторий или лицензию CC BY 4.0;
- помечайте изменения, если вы модифицировали материал.
