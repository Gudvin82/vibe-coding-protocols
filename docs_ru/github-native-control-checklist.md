# GitHub-native Control Checklist

Текущий пакет репозитория: `v0.9.5`

Этот checklist помогает командам проверить GitHub-native controls вокруг
внедрения VCP. Он не означает, что VCP настраивает их автоматически.

## Что проверять

- GitHub Actions PR Gate
- branch protection
- required reviews
- CODEOWNERS
- issue templates
- PR templates
- release notes
- Dependabot
- CodeQL если доступен/включен
- secret scanning если доступен/включен
- security policy
- topics/about/description
- Discussions если планируется community building

## Границы

- VCP не auto-configure GitHub settings.
- VCP не публикует Marketplace action.
- VCP не сертифицирует branch protection, CodeQL или secret scanning.
- VCP помогает командам проверить и задокументировать наличие этих controls.
