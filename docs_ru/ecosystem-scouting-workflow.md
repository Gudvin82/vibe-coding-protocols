# Ecosystem Scouting Workflow

Текущий пакет репозитория: `v0.9.5`

Этот workflow помогает PM, AI product и R&D-командам проверять новые AI-repos
и tools без слепого внедрения.

## Flow

```text
discover
→ classify
→ license/risk review
→ demo suitability
→ VCP route mapping
→ approved / watch / blocked / roadmap-only
```

- не crawler;
- не GitHub scanner;
- не Hugging Face scanner;
- не model registry.
