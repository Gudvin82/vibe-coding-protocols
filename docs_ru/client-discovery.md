# Client Discovery

Используйте этот этап, чтобы понять, где AI coding уже применяется и где находится реальный adoption risk.

Ключевые вопросы:
- Какие команды и репозитории уже используют AI coding?
- Какие инструменты используются: Claude Code, Codex, Cursor, Copilot или другие?
- Что больше всего беспокоит клиента: quality, security, maintainability, legal, speed или cost?
- Какие зоны high-risk или production-critical?
- Какой результат будет считаться успешным пилотом?

Выход:
- recommended offer: VCP-Audit / VCP-Pilot / VCP-Scale
- recommended track
- recommended agent kit
- first risk summary
