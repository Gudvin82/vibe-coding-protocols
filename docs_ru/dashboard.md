# Локальный dashboard

Dashboard в VCP — это локальный статический артефакт.

```bash
vcp dashboard build --output ./vcp-dashboard --json
```

Он показывает:
- версию пакета и методологию;
- track model;
- MVP-to-Launch flow;
- project map;
- run history;
- audit backlog;
- integration status;
- PR Gate и launch decision surfaces.
