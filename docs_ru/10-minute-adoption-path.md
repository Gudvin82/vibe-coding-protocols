# Путь внедрения за 10 минут

1. Прочитай [README_ru.md](../README_ru.md).
2. Запусти `vcp doctor --json`.
3. Запусти `vcp onboard --json` и `vcp classify --json`.
4. Если у тебя уже есть MVP, перейди в [MVP-to-Launch Path](./mvp-to-launch-path.md).
5. Собери локальный dashboard: `vcp dashboard build --output ./vcp-dashboard --json`.
