
# Anti-Chaos Recovery Kit

Этот маршрут нужен, когда AI уже создал хаос и нужно восстановить
контроль.

Сначала freeze changes, потом snapshot current state, затем route
recommender, risk register, audit backlog, recovery track, PR Gate,
evidence bundle и только после этого решение release/hold.

Здесь нет automatic cleanup, automated rewrite или security guarantee.
