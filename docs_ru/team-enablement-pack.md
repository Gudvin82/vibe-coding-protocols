# Team Enablement Pack

Текущий пакет репозитория: `v0.9.4`

Этот pack поддерживает VCP-Pilot и VCP-Scale, превращая ключевые control
surfaces в командный training plan.

## Модули

1. VCP basics.
2. Route selection.
3. Agent kits.
4. Secure AI behavior.
5. PR readiness.
6. Evidence bundle.
7. Release decision.
8. Anti-chaos recovery.
9. Model/tool governance.
10. GitHub-native controls.

## Для каждого модуля фиксируйте

- target audience;
- duration;
- required reading;
- exercise;
- output artifact;
- success criteria.

## Почему это важно

VCP-Pilot часто ломается, если control layer понимает только один maintainer.
Этот pack делает rollout обучаемым, а не purely tribal.
