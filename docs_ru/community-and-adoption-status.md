# Community and Adoption Status

Repository package: `v0.9.0`

VCP пока ранний проект. Stars и публичный размер community — это ограничение, но не единственный maturity signal.

## Честный статус

- проект молодой;
- public adoption proof еще растет;
- низкий star count — это weakness social proof, но не доказательство низкой technical value;
- maturity стоит оценивать по proof surfaces, CLI behavior, tests, manifests и release discipline.

## Оценивайте по proof surfaces

Используйте:
- `docs/proof-snapshot.md`;
- `docs/benchmark-report.md`;
- `docs/trust-check.md`;
- `examples/public-proof/`;
- `case-studies/`.

## Как помочь

- поставить star репозиторию;
- запустить `vcp trust-check --json`;
- открыть issues;
- прислать external evaluation receipt;
- поделиться case study;
- улучшить переводы;
- протестировать VCP с AI agents.

## Чего не нужно выводить

- broad independent adoption, если оно не показано;
- guarantees по stars alone;
- ecosystem maturity только по social proof.
