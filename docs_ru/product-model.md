# Product Model

Repository package: `v0.9.4`

Используй эту модель, чтобы быстро понять VCP.

## Core

Обязательные control-layer surfaces:
- version surfaces;
- CLI;
- track model;
- adopt plan;
- safe apply dry-run;
- release-check;
- PR Gate model;
- cards/index validation;
- trust-check.

## Guided Paths

Пользовательские flows:
- 10-minute adoption path;
- MVP-to-Launch Path;
- spec-driven adoption path;
- local platform flow;
- contracts-first AI-MVP demo;
- SaaS AI-MVP hardening.

## Optional Layers

Полезно, но не обязательно:
- local dashboard artifact;
- project memory;
- audit backlog;
- run state/checkpoints;
- integration packs;
- agent instruction templates;
- docs-site scaffold;
- batch evaluation.

## Roadmap-only

Не shipped:
- hosted dashboard;
- VS Code extension;
- plugin marketplace;
- Go rewrite;
- public PyPI/npm publication;
- remote plugin registry;
- cloud sync.

## Зачем нужна эта модель

Она снижает cognitive load:
- Core объясняет, чем toolkit реально является.
- Guided Paths показывают, как им пользоваться.
- Optional Layers показывают, что можно подключать позже.
- Roadmap-only фиксирует, что нельзя overclaim.
