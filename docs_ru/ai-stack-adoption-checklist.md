# AI Stack Adoption Checklist

Текущий пакет репозитория: `v0.9.5`

Команды часто принимают local/cloud/hybrid AI stack до того, как понимают,
как его нужно проверять. Этот checklist создаёт governance-first intake path.

## Что фиксировать

- какой model/tool stack предлагается;
- local/cloud/hybrid;
- какие данные уходят наружу;
- какой код генерируется;
- какие есть tests;
- какие есть evaluation surfaces;
- какие license применяются;
- какие dependency добавляются;
- какие GitHub controls нужны;
- какой VCP route подходит;
- какой evidence bundle нужен;
- кто одобряет launch.

## Важная граница

VCP не рекомендует один canonical stack.
Он не поставляет local models и не является no-code app generator.
Он помогает проверить стек до внедрения.
