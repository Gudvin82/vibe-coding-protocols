# Vibe Coding Protocols v0.9.0 — Control Catalog, Change Intent, and Adoption Evidence

`v0.9.0` — это первый релиз, который оформляет VCP как более ясную local AI control platform.

## Included

- local AI control platform model;
- control catalog;
- catalog CLI and readable surfaces;
- change intent and spec-delta layer;
- starter adoption matrix;
- agent rule profiles: nano / mini / full;
- project control charter;
- ecosystem map;
- stronger public proof and adoption evidence;
- stronger Russian docs;
- machine-readable sync;
- tests and checks.

## Not included

- hosted platform;
- cloud dashboard;
- official VS Code extension;
- plugin marketplace;
- public PyPI publication;
- public npm publication;
- telemetry;
- cloud sync;
- remote registry;
- credential vault;
- production safety certification;
- launch guarantee;
- SEO or GEO guarantee;
- guaranteed AI citation.
