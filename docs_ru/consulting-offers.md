# Consulting Offers

VCP можно упаковать в три практических формата rollout.
Это consulting/adoption playbooks, а не managed services.

## VCP-Audit
- Длительность: 2–3 недели
- Цель: быстрый аудит рисков и readiness в AI-разработке
- Результаты: discovery summary, technical intake, первый trust-check, initial risk register, первый audit backlog, route recommendation, executive summary

## VCP-Pilot
- Длительность: 6–8 недель
- Цель: controlled rollout для одной команды или одного продукта
- Результаты: customer repo scaffold, agent kit setup, chosen track, PR Gate workflow, backlog operating model, sprint rhythm, pilot metrics, retrospective, scale recommendation

## VCP-Scale
- Длительность: 3–6 месяцев
- Цель: масштабировать operating model на несколько команд
- Результаты: rollout waves, governance reporting, internal ownership, enablement path, maturity checkpoints

## Boundary
- не hosted governance platform
- не compliance certification
- не telemetry
- не automatic monitoring
