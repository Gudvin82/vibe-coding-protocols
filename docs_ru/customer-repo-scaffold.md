# Customer Repo Scaffold

Используйте это как local-first starter structure для client/team rollout.

Рекомендуемый scaffold:
- `.vcp/` context и example artifacts
- `AGENTS.md`
- `PROJECT_CONTROL_CHARTER.md`
- `CHANGE_INTENT.md`
- `PR_GATE.md`
- `LAUNCH_DECISION.md`
- `.github/copilot-instructions.md`
- `.github/workflows/vcp-pr-gate.yml`

Boundary:
- это scaffold template
- не auto-install в repo root по умолчанию
- копирование и export должны быть deliberate
