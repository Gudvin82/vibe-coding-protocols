# Scope Boundary

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

VCP отвечает за control/governance/adoption/proof/evaluation, но не за hosting, deployment, cloud orchestration, marketplace, official plugin suite, native IDE integration или autonomous execution.
## Граница ecosystem layer в v0.9.4

- VCP не поставляет внешние AI tools или модели.
- VCP не является model registry, crawler или hosted discovery service.
- VCP не сертифицирует legal, compliance или vendor security status.
