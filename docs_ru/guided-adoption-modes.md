
# Guided Adoption Modes

Выбирайте самый маленький режим, который всё ещё даёт контроль.

## 5-minute
- откройте `START_HERE.md`;
- запустите `trust-check`;
- откройте route recommender;
- посмотрите flagship demo;
- выберите следующий путь.

## 30-minute
- прочитайте product/control spine;
- получите route recommendation;
- откройте scorecard и proof counts;
- выберите один agent kit.

## Half-day
- соберите evidence bundle inputs;
- прогоните trust-check, cards validate, benchmark run;
- откройте PR readiness и release decision matrix.

## Full audit
- откройте evaluator pack;
- проверьте `.vcp/`, `vcp_cli/`, `tests/`;
- пройдите полный evaluation path.
