# Product Spine

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

Product spine VCP отвечает на вопрос: какая минимальная честная control-цепочка нужна между AI-выводом и безопасным человеческим решением.

VCP не является hosted AI factory и не является autonomous release system.
Это local-first control layer.

Базовый spine:

`Intent -> Route -> Work Package -> Gate -> Proof`

Расширенный spine:

`Intake -> Charter -> Intent -> Route -> Plan -> Work Package -> Gate -> Proof -> Release Decision -> Maintain`
