# Vibe Coding Protocols v0.9.2 — Client Adoption Playbook и rollout-модель AI governance

В релиз вошло:
- Client Adoption Playbook;
- явное definition of success для client/team rollout;
- канонический 8-step client flow;
- три главных entry files для client/team adoption: `START_HERE.md`, `docs/client-adoption-playbook.md`, `docs/integrations/agent-kits.md`;
- форматы VCP-Audit / VCP-Pilot / VCP-Scale;
- guidance для client discovery и technical intake;
- guidance для track selection;
- guidance для customer repo scaffold;
- guidance для executive reporting;
- copy-ready agent kits для Claude Code, Codex, Cursor, GitHub Copilot и GitHub Actions;
- безопасный export flow через `vcp agents kit`;
- CI marker fixes для agent-kit templates;
- исправление stale platform-card smoke count;
- синхронизация machine-readable evaluator/index/catalog surfaces с client adoption story;
- паритет русской методологии для нового client/team adoption narrative.

Не входит в релиз:
- hosted governance platform;
- compliance certification;
- telemetry;
- automatic monitoring;
- cloud sync;
- official IDE extension;
- official plugin suite;
- marketplace;
- native vendor integrations;
- autonomous agent orchestration;
- production safety guarantee;
- launch guarantee.
