# Flagship Demo

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

Flagship demo — канонический 10-минутный сценарий ценности VCP:

`raw AI MVP -> classify -> change intent -> adoption plan -> PR Gate -> trust-check -> dashboard -> launch decision`

Демо синтетическое, но реалистичное. Без секретов, без реальных customer claims и без overclaim.
