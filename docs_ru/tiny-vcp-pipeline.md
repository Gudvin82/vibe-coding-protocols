# Tiny VCP Pipeline

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

Минимальный pipeline VCP:

`Charter -> Intent -> Plan -> Gate -> Proof`

- Charter: правила проекта.
- Intent: что меняется и зачем.
- Plan: как VCP маршрутизирует работу.
- Gate: что должно пройти до PR/release.
- Proof: доказательства без overclaim.
