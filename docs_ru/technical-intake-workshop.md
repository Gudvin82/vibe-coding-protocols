# Technical Intake Workshop

Рекомендуемая длительность: 1–2 часа.

Участники:
- tech lead;
- senior developer;
- product owner при наличии;
- security/compliance representative при необходимости;
- VCP facilitator.

Разделы:
- repo overview;
- architecture surfaces;
- AI usage;
- critical flows;
- risky files/modules;
- tests и CI;
- release flow;
- desired pilot outcome.

Выходы:
- intake summary;
- risk map;
- candidate track;
- первые audit backlog items.
