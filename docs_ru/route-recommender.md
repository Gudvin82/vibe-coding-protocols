
# Route Recommender

Route Recommender помогает выбрать самый честный и минимально достаточный
маршрут VCP.

## Какие сценарии он покрывает

- быстрый MVP;
- новый проект;
- текущий проект;
- raw AI MVP;
- release decision;
- brownfield rescue;
- client rollout;
- AI chaos recovery;
- deep hardening.

На выходе вы получаете route, rigor mode, agent kit, required surfaces,
first commands и next path.
