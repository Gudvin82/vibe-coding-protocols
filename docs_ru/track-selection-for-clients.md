# Track Selection For Clients

Выбирайте самый маленький и честный track.

Примеры:
- raw AI MVP -> MVP-to-Launch
- messy existing repo -> Brownfield Rescue или Deep Hardening
- one-team controlled rollout -> Controlled Delivery Pilot
- early structured build -> New Project

Для каждого выбора определите:
- rigor mode
- required artifacts
- recommended agent kit
- first commands
- proof requirements
