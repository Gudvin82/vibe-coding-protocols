# Control Spine

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

VCP Control Spine — канонический продуктовый spine для контролируемой AI-assisted delivery.

Короткий spine:

`Charter -> Intent -> Plan -> Gate -> Proof`

Полный spine:

`Intake -> Charter -> Intent -> Route -> Plan -> Work Package -> Gate -> Proof -> Release Decision -> Maintain`

Каждый этап задает purpose, input, output artifact, related command и типовые риски. Начинайте с short spine, а полный используйте для controlled/launch/deep-hardening режимов.
