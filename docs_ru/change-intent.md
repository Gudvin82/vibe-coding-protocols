# Change Intent

Repository package: `v0.9.5`

Change Intent — это локальный control-layer VCP для planned change.

Перед тем как AI-агент меняет код, проект может зафиксировать:
- что меняется;
- зачем меняется;
- какой ожидается user/business outcome;
- какие surfaces затронуты;
- какой риск;
- какие проверки обязательны;
- какой путь VCP рекомендуется;
- нужен ли human approval;
- как откатиться.
