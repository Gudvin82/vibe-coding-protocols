# Integration Packs

Integration pack — это локальный copyable setup bundle.

Он может быть:
- `shipped`
- `local-template`
- `experimental`
- `roadmap`
- `not-shipped`

Используй `vcp integrations packs --json`, чтобы увидеть текущий список.

Это локальные setup bundles, а не official integrations и не marketplace installs.
