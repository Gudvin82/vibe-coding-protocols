# Agent Harness Check Command

Use when you want to check whether a repository already has a usable AI delivery harness.

Prompt:

Check whether this project has:
- project memory;
- stop conditions;
- validation gates;
- review loop;
- security baseline;
- release or rollback notes.

Return:
- what exists;
- what is weak;
- what is missing;
- the smallest next improvement.

Do not implement broad changes before reporting the harness gaps.
