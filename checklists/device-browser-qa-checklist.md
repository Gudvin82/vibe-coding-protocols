# Device / browser QA checklist

## When to use

Перед deploy публичного web/MVP.

## Checklist
- mobile viewport checked
- Safari / iOS WebView checked
- Chrome Android checked
- desktop Chrome/Firefox checked
- auth/session edge cases checked
- payment/webhook UX checked if active
