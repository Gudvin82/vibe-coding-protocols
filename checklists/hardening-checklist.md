# Hardening checklist

## When to use

Перед merge / deploy / production-like claims.

## Checklist
- mode selected: Light / Standard / Full
- code discovery done
- PROJECT_MAP / ARCHITECTURE updated
- findings classified
- scanners run or marked not run
- self-protection reviewed
- database/load reviewed
- final report created
- AUDIT_BACKLOG updated
