# Auth Abuse Checklist

- [ ] Login endpoint rate-limited
- [ ] Password reset endpoint rate-limited
- [ ] Registration endpoint rate-limited
- [ ] Admin login protected by MFA or stronger controls
- [ ] Failed login spikes monitored
- [ ] Credential stuffing response documented
- [ ] Invisible captcha / challenge considered
- [ ] Password hashing algorithm documented
- [ ] Session cookie flags checked
- [ ] User enumeration prevented
- [ ] Brute-force test performed safely
