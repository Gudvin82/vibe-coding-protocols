# Starter checklist

## When to use

Перед первой AI-итерацией.

## Checklist
- Product Brief created
- active / deferred surfaces defined
- stack chosen intentionally
- README / AGENTS / PROJECT_MAP / ARCHITECTURE created
- operational baseline decided
- safe third-party intake reviewed
- first vertical slice scoped
