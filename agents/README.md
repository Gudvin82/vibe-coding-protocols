## How to use

1. Copy the root quick-start file or the matching detailed example into your project.
2. Add project-specific paths, commands and approval gates.
3. Pair it with the relevant protocol in [`../protocols/`](../protocols/).
4. Keep project-sensitive versions private / sanitized / encrypted when needed.
