# Cursor Composer workflow

When the user says "build feature":

1. Read `PROJECT_MAP.md`, `AGENTS.md` and `README.md`.
2. Identify active and deferred surfaces.
3. Ask the AI for a compact evidence map first if broad discovery is needed.
4. Propose a plan.
5. Ask for approval.
6. Edit the smallest practical diff.
7. Run validation.
8. Update the Memory Bank.
9. Report changed files, validation, risks and follow-up work.

Do not let the AI scan and rewrite the whole project in one step.
