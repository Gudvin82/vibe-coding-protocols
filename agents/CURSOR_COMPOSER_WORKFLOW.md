# Cursor Composer workflow

When the user says "build feature":

1. Read `PROJECT_MAP.md`, `AGENTS.md` and `README.md`.
2. Identify active and deferred surfaces.
3. Propose a plan.
4. Ask for approval.
5. Edit the smallest practical diff.
6. Run validation.
7. Update the Memory Bank.
8. Report changed files, validation, risks and follow-up work.
