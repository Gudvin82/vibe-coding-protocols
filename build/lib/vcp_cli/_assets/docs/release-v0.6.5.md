# Vibe Coding Protocols v0.6.5 — Project Memory, Pack Security, and Public Growth Evaluation

v0.6.5 adds focused governance polish: a VCP project memory model, operating principles, protocol-pack security rules, proactive VCP routines, and an evaluation path for the SEO/GEO/AI public-growth structure so external AI agents can inspect it as a first-class artifact without overclaiming rankings or AI citation guarantees.

## Included in this release

- File-based project memory model for VCP memory surfaces and update rules.
- Principles document that clarifies VCP identity and refusal boundaries.
- Protocol-pack security model, trust levels, and review template.
- Repeated proactive VCP routines for merge, release, backlog, production, and spec freshness.
- SEO/GEO/AI structure evaluation path for Public Growth as a structured artifact.
- Explicit repository-package vs methodology version semantics.
- Updated ecosystem reference boundaries, cards, manifests, reports, and benchmarks.

## Boundaries preserved

- no personal-assistant scope creep;
- no autonomous proactive agents;
- no cloud runtime or computer-use layer;
- no Vellum compatibility, copying, or endorsement claim;
- no fake public proof or benchmark claims;
- no ranking or AI citation guarantees.
