# GitHub Security Settings

These settings are useful when available on your GitHub plan.

## Recommended manual settings

- enable Dependabot alerts;
- enable Dependabot security updates;
- enable secret scanning, if available;
- enable code scanning, if available.

## Notes

Availability depends on repository type and GitHub plan.
Do not assume every feature exists everywhere.

These settings complement the toolkit.
They do not replace project-specific review, validation or incident handling.
