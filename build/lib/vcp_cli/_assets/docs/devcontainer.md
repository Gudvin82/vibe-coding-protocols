# Dev Container

The Dev Container in this repository is optional.

Use it when you want isolated checks with:
- bash;
- git;
- python3;
- node and npm;
- shellcheck when available.

It is useful for:
- onboarding on a clean machine;
- validating scripts in a reproducible shell;
- running toolkit checks without polluting the host system.

It is not required to use the repository.

It does not include production secrets or auto-run scanners.
