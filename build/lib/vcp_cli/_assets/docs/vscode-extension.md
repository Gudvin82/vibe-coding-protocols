# VS Code Extension Skeleton

The repository now contains an experimental contributor skeleton in `vscode-extension/`.

## What it is for

It shows how a future extension could:
- open `START_HERE.md`;
- open `templates/ARCHITECTURE_MAP.md`;
- run `bash scripts/vibe-check.sh --doctor`;
- initialize a Lite route later.

## What it is not

- not published to the VS Code Marketplace;
- not a production extension;
- not a promise of feature completeness.

## Current commands

- `VCP: Initialize Lite`
- `VCP: Run Doctor`
- `VCP: Open START_HERE`
- `VCP: Open Architecture Map Template`
