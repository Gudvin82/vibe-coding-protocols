# 10-Minute Adoption Path

1. Run `python3 -m vcp_cli doctor --json`.
2. Run `python3 -m vcp_cli onboard --json`.
3. Run `python3 -m vcp_cli classify --json`.
4. If the repo is a raw or semi-working AI MVP, continue into `docs/mvp-to-launch-path.md`.
5. Choose `brownfield-rescue`, `spec-foundation`, or `saas-ai-mvp-hardening`.
6. Preview adoption with `vcp adopt plan --json`.
7. Check release and PR Gate before merge or launch decisions.
