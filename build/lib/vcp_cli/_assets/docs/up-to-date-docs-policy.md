# Up-to-date Docs Policy

AI coding agents often rely on stale API knowledge.

Before adding or upgrading libraries:
- identify exact package and version;
- check official docs;
- check migration notes;
- check breaking changes;
- prefer current docs over memory.

If your AI IDE supports Context7, MCP docs, or another live-docs provider, use it for library-specific implementation details.

If live docs are unavailable:
- paste relevant docs;
- link official docs;
- record the assumption in `AUDIT_BACKLOG.md`.
