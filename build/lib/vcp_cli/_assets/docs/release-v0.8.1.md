# Vibe Coding Protocols v0.8.1 — 10-Minute Adoption Path, Killer Demo, and Product Narrative Sync

`v0.8.1` is a focused product-clarity release.
It does not add a new big architecture layer.
It makes the first-user journey, MVP adoption story, and proof language easier to understand and harder to overclaim.

## What changed

- synchronized current public and AI-facing version surfaces for `v0.8.1`;
- added a 10-minute adoption path from install to launch check;
- added a raw AI-MVP to controlled-launch demo;
- added a concise MVP Adoption Track;
- strengthened the proof layer and adoption case-study structure;
- documented integration roadmap surfaces without pretending implementation.

## Why this release exists

The previous release made VCP more installable and operational.
`v0.8.1` makes it easier for a first-time user to understand the story:

- build with AI;
- choose the right track;
- adopt safely;
- ship with control.

## Included in this release

- short first-user adoption path;
- killer demo for a raw AI-generated MVP;
- clearer product narrative across README, AI guidance, cards, and release notes;
- stronger proof/case-study guidance;
- integration roadmap documentation with explicit boundaries.

## Not included

This release does not ship:
- public PyPI publication;
- public npm publication;
- official VS Code extension;
- marketplace GitHub Action;
- web dashboard implementation;
- plugin marketplace;
- integration engine rewrite;
- production safety guarantees;
- SEO/GEO ranking guarantees;
- guaranteed AI citation.

## Boundaries preserved

- safe apply remains non-destructive by default;
- workflow runner remains a safe preview path, not a hidden automation engine;
- public proof remains conservative and labeled;
- integrations remain documented honestly as shipped, local, template-based, or roadmap-only.
