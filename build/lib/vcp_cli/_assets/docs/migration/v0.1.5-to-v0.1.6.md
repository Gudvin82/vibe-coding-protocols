# Migration: v0.1.5 to v0.1.6

## What changed

- Added `scripts/install-hooks.sh`
- Added `scripts/extract-prompt.sh`
- Added modular prompt files under `prompts/modules/`
- Added a runnable `examples/todo-app-starter/`
- Added docs navigation indexes and migration notes
- Added stronger `vibe-check.sh` help, JSON output and lock/secret checks

## What to copy

- `scripts/install-hooks.sh`
- `prompts/modules/`
- `scripts/extract-prompt.sh`
- `templates/AGENTS.claude.md`
- `templates/AGENTS.cursor.md`
- `templates/AGENTS.windsurf.md`
- `prompts/backlog-to-issues-prompt.md`

## Do users need to update AGENTS.md?

Yes, if they want the new operational Stop Conditions and discovery-agent guidance.

## Did vibe-check behavior change?

Yes. It now supports `--help`, `--json`, more secret-like patterns and soft lockfile checks.

## Backward compatibility notes

- Default mode still treats WARN as exit code `0`.
- External scanners remain optional.
- Existing `master-prompt-full.md` is still valid.
