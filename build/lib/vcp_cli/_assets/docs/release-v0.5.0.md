# Vibe Coding Protocols v0.5.0 — Product-Grade CLI, Manifests, Benchmarks, and Adoption Framework

## Summary

v0.5.0 upgrades VCP from a markdown-first protocol toolkit into a product-grade AI delivery framework.
It adds a unified local CLI surface,
machine-readable manifests,
route selection,
adoption dry-run planning,
maturity scoring,
AI adoption benchmarks,
demo output,
sanitized case-study structure,
docs-site readiness,
and stronger community and adoption workflows.

## What changed

- Added a real local `vcp_cli` surface.
- Added machine-readable manifests for routes, packs, commands, reports and benchmarks.
- Added benchmark scenarios for AI adoption routing.
- Added demo docs and terminal demo output.
- Added sanitized case-study structure.
- Added hosted docs readiness docs.
- Added community templates and contribution polish.
- Preserved script-first workflows and wrapped them with `vcp check`.

## Compatibility

- Repository package: `v0.5.0`
- Methodology version remains `v1.4`
- Existing scripts remain supported.
- Adoption stays dry-run by default.
