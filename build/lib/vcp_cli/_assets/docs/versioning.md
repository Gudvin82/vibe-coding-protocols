# Versioning

This project uses one public current-release label and one internal stable-method label.

- Repository package `v0.8.4` — the current GitHub toolkit release: installable CLI, npm wrapper, manifests, cards, benchmarks, tests, examples, CI, and docs.
- Stable methodology reference `v1.4` — a legacy/internal method-layer marker that may span multiple repository package releases.

Repository package versions track the current GitHub-distributed toolkit.
The stable methodology reference is not the current GitHub release label.

Current repository package: `v0.8.4`.

When citing the current GitHub release, use `Vibe Coding Protocols v0.8.4`.
Do not cite the current repository release as `v1.4`.
