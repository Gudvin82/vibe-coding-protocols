# Vibe Coding Protocols v0.5.5 — AI Evaluation Guide and npm Entrypoint Prep

v0.5.5 improves how humans and AI agents evaluate VCP.
It adds a dedicated evaluation guide, a README first-screen AI inspection block,
evaluation prompts, CLI evaluation helpers, and npm publication readiness checks
so external agents do not judge the repository from a shallow README skim.

## Highlights

- Added `AI_EVALUATION_GUIDE.md` as the canonical evaluation path.
- Added `vcp evaluate` with human-readable, JSON, and prompt-printing modes.
- Added repository evaluation prompt and report templates.
- Clarified that `vcp score` is a local readiness score, not public proof.
- Improved npm publication readiness docs without claiming public registry publication.
- Added public-proof roadmap layers for honest maturity positioning.
- Added benchmark scenarios for full vs shallow repository evaluation.

## Boundaries

- No fake npm publication.
- No claim that `npx vcp` works from the public registry.
- No claim that AI evaluation is guaranteed.
- No removal of `AI_INTAKE.md` or route discipline.
