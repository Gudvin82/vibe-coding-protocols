# IDE Plugins Status

## Current status

VCP does not currently ship a mature published IDE plugin.

What exists today:
- documentation;
- prompts;
- rules files;
- manual copy workflows;
- an experimental VS Code extension skeleton if you want contributor context.

## What plugin-ready would mean

A mature plugin-ready VCP experience would include:
- an installable package;
- tested activation;
- command palette actions;
- route chooser UI;
- rule or template installer;
- validation runner;
- update and migration assistant.

## Current manual integrations

- Claude Code
- Codex
- Cursor
- Windsurf
- GitHub Copilot
- JetBrains / Junie

See [integrations/README.md](./integrations/README.md).

## Future work

Possible future work:
- VS Code extension beyond skeleton state;
- Cursor/Windsurf rules installer;
- Copilot instructions generator;
- JetBrains integration notes;
- unified `vcp` route chooser.

Do not treat current docs and skeletons as a mature plugin marketplace.
