# Vibe Coding Protocols v0.6.0 — Adaptive Spec Depth, Presets, and 25+ Platform Paths

`v0.6.0` expands VCP beyond a single spec-first lane. It adds adaptive spec depth, a spec escape hatch for genuinely tiny work, a question engine for one-question-at-a-time clarification, spec retrofit and freshness workflows for existing repos, lightweight presets, and a 25+ platform documentation/card layer for AI-tool usage paths.

## Added in `v0.6.0`

- Adaptive Spec Depth docs, protocol, CLI helpers, and benchmark scenarios.
- Spec Escape Hatch guidance and safe/unsafe skip-check behavior.
- Question Engine prompts and report surfaces for low-friction clarification.
- Spec Retrofit and Spec Freshness layers for existing codebases with weak or drifting project memory.
- Presets as guidance-only defaults for solo founders, SaaS, legaltech, agency-client, and public-site work.
- Expanded platform coverage to 25+ documented repository workflow paths.
- Platform, preset, workflow, and diagnostic card types plus synced index/catalog metadata.
- A sanitized retrofit/public-growth case-study packet without fake metrics.

## What `v0.6.0` does not claim

`v0.6.0` does **not** claim:

- official vendor plugins where only repository docs exist;
- marketplace integration or endorsement for documented AI tools;
- destructive preset apply flows;
- perfect spec-depth classification or automatic product discovery;
- automatic code rewriting from the retrofit lane;
- guaranteed AI citation, indexing, ranking, or AI Overview placement;
- fake adoption, fake case-study metrics, or copied external frameworks.

## Why this release matters

Before `v0.6.0`, VCP had a strong spec lane but still needed a lighter answer for tiny tasks, a clearer retrofit path for already-existing code, and more realistic defaults for different project shapes. This release makes VCP less bureaucratic for small work and more explicit for risky work, while also making repository usage clearer across many AI platforms without overclaiming integration maturity.
