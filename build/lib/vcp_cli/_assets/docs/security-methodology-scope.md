# Security Methodology Scope

Use this page to separate repository policy from project security work.

## What VCP can help with

- make security-relevant decisions explicit
- route projects toward Hardening or Extended review
- preserve written risk and review artifacts
- require post-task review before sensitive changes are accepted

## What VCP cannot guarantee

- production safety
- absence of vulnerabilities
- legal compliance
- dependency or supply-chain safety
- correct infrastructure configuration
- that AI-generated code is safe without review

## Security-sensitive work

Auth,
session,
permissions,
payments,
personal data,
public API security behavior
and incident work still require Hardening,
independent human review
or both.
