# SEO / GEO / AI Structure Evaluation

This is VCP's structured public-growth evaluation surface.
It is not a promise of rankings, indexing, citation, AI Overview inclusion, or answer-engine placement.

## Practical CLI pairing

```bash
python3 -m vcp_cli public-growth check --json
```

## Evaluation dimensions

1. technical SEO readiness
2. AI-readable surfaces
3. entity clarity
4. trust and proof pages
5. FAQ/comparison/glossary presence
6. case-study and source-of-truth evidence
7. no-overclaim policy
8. update cadence

## Hard boundaries

- no ranking guarantees;
- no AI overview or citation guarantees;
- no fake reviews;
- no black-hat SEO.
