# Measured Impact

VCP does not claim real outcome metrics unless they were actually measured and sanitized for publication.

## What can be measured later

Examples of acceptable measured fields:
- number of AI-generated issues caught by post-task review
- number of missing registry entries found
- number of release-blocking findings
- number of unsafe external API additions prevented
- validation failures found before merge
- time to adoption
- route selected vs route initially guessed by AI
- before/after maintainability findings

## What must not be claimed without evidence

- reduced bugs by a percentage without measurement
- improved security by a percentage without measurement
- production performance gains without evidence
- real customer claims without approval and sanitization

## Labels to use

- `synthetic` = example only
- `sanitized` = based on a real pattern but cleaned for publication
- `measured` = real tracked data with publication approval
