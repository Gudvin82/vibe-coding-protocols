# Example: small landing fast track

## Context

Нужен простой landing с формой заявки.

## Route

- Product Brief
- Starter Prompt 0
- Stack decision
- README + AGENTS + PROJECT_MAP
- first safe slice
- optional Light Hardening before deploy

## Why this is enough

Нет сложной domain logic, нет payments, нет heavy integrations.
Но даже здесь полезны stop conditions, clear scope и basic hardening.
