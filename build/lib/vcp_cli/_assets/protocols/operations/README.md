# Operations

Use this family when the project is already running and the next safe step is read-only observation, error capture, or structured triage.

## Included workflows

- [production-error-capture.md](./production-error-capture.md)
- [daily-error-triage.md](./daily-error-triage.md)

## Core boundary

Operations monitoring in VCP is read-only by default.
Capture and triage can prepare safer follow-up work, but they do not fix, deploy, reconfigure, restart, or root-cause production on their own.
