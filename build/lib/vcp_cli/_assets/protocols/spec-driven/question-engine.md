# Question Engine

The question engine exists to ask only the necessary clarifying questions.

## Rules

- Ask one question at a time.
- Prefer multiple-choice by default.
- Keep an `Other / not sure` option.
- Stop when enough information exists.
- Do not overwhelm the user with a giant discovery form.

## Categories

- user/persona
- problem
- success criteria
- constraints
- data and integrations
- security/privacy
- UI/UX
- rollout/release
