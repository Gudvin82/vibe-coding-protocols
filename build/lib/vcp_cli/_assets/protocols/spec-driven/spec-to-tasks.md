# Spec to Tasks

`vcp-version: v0.5.9`

Purpose: break an accepted feature spec into concrete tasks.

Task slicing rules:
- one task should have one clear completion signal;
- tasks should link back to acceptance criteria;
- validation work is a first-class task, not an afterthought;
- architecture or migration work must be explicit;
- release or review gates must not be hidden inside coding tasks.
