# Integrations

Use this lane when an AI agent wants to add or change a dependency on any external API, SDK, webhook provider, SaaS integration or third-party data source.

## Use this when

- a feature proposal depends on an external API;
- an SDK would send or receive data from a third-party system;
- a webhook provider, analytics tool, chat widget, map provider or public API is being introduced;
- the project needs a registry entry, fallback plan or data-handling review before implementation.

## Core rule

No external API dependency goes into production code without classification, registry entry, data and risk review, fallback plan and validation.
