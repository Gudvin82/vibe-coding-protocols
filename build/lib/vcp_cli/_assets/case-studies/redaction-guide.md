# Redaction Guide

Use this before sharing any real project feedback.

## What to share

- sanitized routes and artifact choices;
- generalized findings categories;
- redacted screenshots when safe;
- before/after process notes;
- which AI IDE and route were used.

## What not to share

- secrets;
- customer data;
- internal URLs;
- raw production logs;
- private architecture diagrams;
- screenshots with tokens or account details.

## Screenshot rule

Screenshots are allowed only when all sensitive data is removed.
If in doubt, rewrite the evidence as text instead.
