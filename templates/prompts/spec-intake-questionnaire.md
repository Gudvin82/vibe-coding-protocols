# Spec Intake Questionnaire

Use this prompt to clarify an idea before implementation.

Ask for:

- primary user;
- problem being solved;
- success signal;
- non-goals;
- constraints;
- data, privacy, auth, payment, or external API impact;
- rollout expectations;
- validation expectations.

Do not jump into implementation before the answers are visible.
