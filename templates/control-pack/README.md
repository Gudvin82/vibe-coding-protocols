# Portable Control Pack

Copy these files into your project to get the minimum VCP control layer.

Included:
- `PROJECT_CONTROL_CHARTER.md`
- `CHANGE_INTENT.md`
- `AGENT_RULES.nano.md`
- `AGENT_RULES.mini.md`
- `PR_GATE.md`
- `LAUNCH_DECISION.md`
- `.vcp-control-pack.json`

This is a local portable scaffold, not a hosted platform, marketplace, or autonomous agent system.
