# Public Site Templates

These templates help publish AI-assisted products or documentation sites more safely.

Use placeholders only.
Do not ship fake URLs,
hidden FAQ content
or schema that does not match visible page content.

Included templates:
- `llms.txt`
- `robots.txt`
- `schema-org.organization.jsonld`
- `schema-org.website.jsonld`
- `schema-org.software-source-code.jsonld`
- `schema-org.breadcrumb-list.jsonld`
- `schema-org.faq-page.jsonld`
