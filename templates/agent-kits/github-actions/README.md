# GitHub Actions PR Gate Kit

This is a copy-ready VCP setup kit for GitHub Actions.

Copy into your target repository:
- `vcp-pr-gate.yml` -> `.github/workflows/vcp-pr-gate.yml`
- `PR_GATE.md` -> `PR_GATE.md`
- `LAUNCH_DECISION.md` -> `LAUNCH_DECISION.md`

Recommended next step:
- use this as a repository-side PR Gate example and keep human review for release decisions.

Boundary:
- not a marketplace integration;
- not native GitHub governance;
- not auto-merge or auto-launch orchestration.
