# Security Policy

## Scope

Этот файл относится к самому репозиторию `vibe-coding-protocols`, а не к какому-то production-продукту.

## Please do not submit

Не присылайте в issues, PR или discussions:
- реальные secrets, tokens, API keys;
- private architecture docs реальных проектов;
- production `.env`;
- customer data;
- внутренние IP, private endpoints и incident details.

## If you found a problem

Если вы нашли:
- ошибку в шаблоне;
- опасную формулировку;
- misleading recommendation;
- security-sensitive issue в публичном markdown toolkit,

лучше сначала сообщить автору через сайт:
[https://anmalishev.ru/](https://anmalishev.ru/)

## Public vs private reminder

Этот репозиторий содержит только публичные templates.
Реальные проектные `AGENTS.md`, `PROJECT_MAP.md`, `ARCHITECTURE.md`, incident runbooks и operational docs должны храниться private / sanitized / encrypted.
