# Tooling Roadmap

VCP is now script-first plus a local product layer.

## Available in v0.5.0

- local CLI surface via `python3 -m vcp_cli`
- route selection
- adoption dry-run planning
- review plan helper
- score report
- machine-readable manifests
- benchmark scenario validation
- demo output
- script checks and readability checks

## What tooling can catch today

- missing structure
- version drift
- broken local markdown links
- newline-poor docs
- basic toolkit consistency
- missing manifest references
- benchmark metadata drift

## What still requires human review

- architecture quality
- whether a refactor is worth doing
- production security posture
- business logic correctness
- legal or compliance needs
- whether an independent review is strong enough for sensitive changes

## Still future

- PyPI, npm or Homebrew distribution
- mature IDE plugins
- deep AST boundary linting
- graphical project map
- automatic migration assistant
- hosted docs site publishing
- external AI reviewer orchestration
- real scanner integrations
