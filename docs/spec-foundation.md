# Spec Foundation

VCP Spec Foundation turns an idea into controlled project memory, backlog, architecture context, and review gates.

## What this is

A VCP-native path for creating enough product and spec structure before AI implementation starts.

## What this is not

- not a Spec Kit clone;
- not a replacement for product judgment;
- not a guarantee that AI will implement correctly;
- not mandatory for tiny tasks.

## Core flow

```text
idea -> questions -> product brief -> PRD/feature spec -> acceptance criteria -> tasks -> backlog -> architecture memory -> review/release gates
```

## Minimum path

For small features:

- one-page feature brief;
- acceptance criteria;
- validation plan;
- backlog item.

## Full path

For complex or high-risk work:

- product brief;
- PRD;
- feature spec;
- acceptance criteria;
- tasks;
- risk review;
- architecture impact;
- review and release gates.

## Governed path

For production, data, payment, auth, or regulatory work:

- full path;
- release readiness;
- rollback plan;
- third-party review;
- PR Gate.

## Why it matters

Spec Foundation is how VCP helps a new AI-assisted product avoid turning implementation into hidden product discovery.
