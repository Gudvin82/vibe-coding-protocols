# Project Memory

VCP project memory is explicit, local, file-based, reviewable, and project-scoped.

It is not personal assistant memory.
It does not infer personality.
It does not send proactive notifications.
It does not sync to a cloud service.

## Files

- `.vcp/project-memory.example.json`
- optional `.vcp/project-memory.schema.json`

## What to store

- active decisions;
- open risks;
- blockers;
- proof history;
- the current track and methodology reference.

## Why it exists

Project memory keeps adoption and release control visible across sessions, tools, and agents.
