# AI Stack Adoption Checklist

Repository package: `v0.9.4`

Teams often adopt a local/cloud/hybrid AI stack before they know how it should
be reviewed. This checklist creates a governance-first intake path.

## What to document

- what model/tool stack is proposed;
- local/cloud/hybrid;
- what data is sent out;
- what code is generated;
- what tests exist;
- what evaluation exists;
- what licenses apply;
- what dependencies are added;
- what GitHub controls are needed;
- which VCP route applies;
- which evidence bundle is required;
- who approves launch.

## Important boundary

VCP does not recommend one canonical stack.
It does not ship local models or no-code app generation.
It helps teams review the stack before adoption.
