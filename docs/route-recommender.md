
# Route Recommender

Route Recommender helps new users pick the smallest honest VCP route.

## Scenarios

- fast-mvp
- new-project
- existing-project
- raw-ai-mvp
- release-decision
- brownfield-rescue
- client-rollout
- ai-chaos-recovery
- deep-hardening

Each recommendation returns:
- route;
- rigor mode;
- recommended agent kit;
- required surfaces;
- first commands;
- evidence expectations;
- stop conditions;
- next path.
