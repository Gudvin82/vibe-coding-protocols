# Presentations

Repository package: `v0.8.9`

Presentations are optional public proof assets, not required runtime features.

## Expected destination

- `assets/presentations/vcp-overview-en-v0.8.9.pdf`
- `assets/presentations/vcp-overview-en-v0.8.9.pptx`
- `assets/presentations/vcp-overview-ru-v0.8.9.pdf`
- `assets/presentations/vcp-overview-ru-v0.8.9.pptx`

## Rules

- prefer PDF for GitHub viewing;
- include PPTX only if size is reasonable;
- do not include copyrighted third-party logos unless allowed;
- export reusable diagrams separately to `assets/diagrams/`.

The destination is prepared in this release. Presentation files themselves are optional.
