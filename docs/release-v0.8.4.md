# Vibe Coding Protocols v0.8.4 — MVP-to-Launch Path and Local Platform Flow

`v0.8.4` organizes the existing VCP control surfaces into a clearer user-facing launch path for raw or semi-working AI-generated MVPs.

VCP still has two core tracks:
- New Project Track
- Existing Project Track

MVP-to-Launch is a first-class guided path under Existing Project Track.

## Included in this release

- MVP-to-Launch guided path;
- clear relationship to Existing Project Track;
- local launch readiness flow;
- MVP route/readiness dashboard view;
- MVP-to-Launch workflow plan;
- launch decision checklist;
- demo updates connecting raw AI-MVP, SaaS AI-MVP, contracts-first, PR Gate, proof, project memory, and dashboard;
- machine-readable cards, benchmarks, and manifests for MVP-to-Launch.

## Not included

- hosted dashboard;
- hosted launch platform;
- VS Code extension;
- plugin marketplace;
- Go rewrite;
- public PyPI publication;
- public npm publication;
- cloud sync;
- telemetry;
- remote plugin registry;
- credentials vault;
- autonomous background notifications;
- production safety guarantee;
- launch guarantee;
- SEO/GEO ranking guarantee;
- guaranteed AI citation.
