# Client Discovery

Use this stage to understand where AI coding already lives and what the real adoption risk is.

Core questions:
- Which teams and repos already use AI coding?
- Which tools are in use: Claude Code, Codex, Cursor, Copilot, or other?
- What worries the client most: quality, security, maintainability, legal, speed, or cost?
- Which areas are high-risk or production-critical?
- What outcome would make the pilot successful?

Output:
- recommended offer: VCP-Audit / VCP-Pilot / VCP-Scale
- recommended track
- recommended agent kit
- first risk summary
