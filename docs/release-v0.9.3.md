# Vibe Coding Protocols v0.9.3 — Route Recommender, Evidence Bundle, and PR/Integration Proof

## Release theme

Public clarity, route recommender, control scorecard, evidence bundle,
PR readiness, integration proof, visual layer, and honest limitations.

## Included

- proof count synchronization model;
- current limitations page;
- route recommender;
- control scorecard;
- evidence bundle;
- release decision matrix;
- anti-chaos recovery kit;
- guided adoption modes;
- PR readiness pack;
- PR evidence checklist;
- PR handoff bundle;
- integration proof matrix;
- AI tool mode packs;
- visual diagrams for route selector, evidence bundle, PR flow, release
  decision matrix, and anti-chaos recovery;
- evaluation status badge model;
- trust-check coverage;
- Russian docs parity;
- no-overclaim boundary.

## Why it matters

`v0.9.3` makes VCP easier to route, easier to explain, and easier to hand
off without pretending it is a hosted governance platform.

## Not included

- SaaS;
- hosted dashboard;
- PyPI/npm publication;
- official VS Code extension;
- marketplace;
- automatic PR creation;
- auto-merge;
- full security scanner;
- telemetry;
- cloud sync;
- incident monitoring automation;
- compliance certification.

## How to verify

```bash
python3 -m vcp_cli route list --json
python3 -m vcp_cli route recommend --scenario raw-ai-mvp --json
python3 -m vcp_cli scorecard --json
python3 -m vcp_cli pr readiness --json
python3 -m vcp_cli trust-check --json
```
