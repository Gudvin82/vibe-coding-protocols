# Project Map

Use the root [PROJECT_MAP.md](../PROJECT_MAP.md) as the repository-level routing and architecture snapshot.

The local dashboard project map view summarizes:
- repository package and methodology;
- track model and MVP-to-Launch path;
- docs and workflows;
- integration packs and integration status;
- project memory;
- run state and run history source;
- PR Gate approval model;
- audit backlog;
- launch decision checklist;
- dashboard artifact outputs.

`project-map.json` is a read-only local summary, not a remote inventory service.
