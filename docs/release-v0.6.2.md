# Vibe Coding Protocols v0.6.2 — AI Intake Enforcement and Shallow Evaluation Prevention

`v0.6.2` strengthens VCP's first-contact experience for AI IDEs and coding agents. It adds a forced AI inspection path in README and README_ru, introduces `TAKE_THIS_FIRST.md`, updates `AGENTS.md`, `.vcp/index.json`, cards and evaluation guidance, and adds shallow-evaluation benchmarks so agents do not judge or adopt VCP from README alone.

## Added in `v0.6.2`

- top-of-README AI enforcement blocks in English and Russian;
- root `TAKE_THIS_FIRST.md` for adoption-from-link requests;
- stronger `AGENTS.md` routing for evaluation vs adoption;
- `.vcp/index.json` AI summary plus shallow-evaluation warning;
- `ai-intake-enforcement` concept card;
- adoption-from-link prompt and decision report template;
- shallow README evaluation trap benchmark;
- `vcp evaluate` shallow/full inspection metadata.

## What `v0.6.2` does not claim

`v0.6.2` does **not** claim:
- that AI agents will always follow repository instructions;
- guaranteed correct AI evaluation;
- official IDE or plugin integrations;
- guaranteed citation, indexing, or ranking;
- that target projects should copy the whole VCP repository.
