# Ecosystem Scouting Workflow

Repository package: `v0.9.4`

This workflow helps PM, AI product, and R&D teams review new AI repos and tools
without adopting them blindly.

## Flow

```text
discover
→ classify
→ license/risk review
→ demo suitability
→ VCP route mapping
→ approved / watch / blocked / roadmap-only
```

- [AI Ecosystem Watchlist](./ai-ecosystem-watchlist.md)

## Why this exists

Scouting should produce a governance artifact, not just a Slack message or a
bookmark list.

## What this is not

- not a crawler;
- not a GitHub scanner;
- not a Hugging Face scanner;
- not a model registry.
