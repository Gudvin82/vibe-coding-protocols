# Vibe Coding Protocols v0.6.3 — Demo, Install, and Visual Adoption Polish

v0.6.3 improves VCP’s first human impression after the AI-intake guardrails in v0.6.2. It adds a 2-minute demo path, Mermaid lifecycle diagrams, clearer install guidance, score badge adoption docs, stronger case-study proof surfaces, README_ru parity checks, and first-impression benchmarks without adding a new framework layer.

## Included in this release

- Mermaid-first visual onboarding docs and source diagrams.
- A compact 2-minute human demo path.
- Honest install guidance for Python, editable install, Windows launcher, and local npm wrapper usage.
- Stronger score badge adoption guidance with explicit non-certification language.
- Stronger sanitized case-study proof framing and validation notes.
- README_ru parity checking and first-impression audit scenarios.
- Synced cards, index, manifests, and benchmark metadata for the new onboarding layer.

## Boundaries preserved

- no fake GIFs or screenshots;
- no npm, npx, or PyPI publication claims;
- no score badge certification claims;
- no AI citation, indexing, or ranking guarantees;
- no official IDE/plugin overclaim.
