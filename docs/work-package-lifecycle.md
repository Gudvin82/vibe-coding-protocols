# Work Package Lifecycle

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

Work package lifecycle:

`planned -> in_progress -> for_review -> approved -> done`

A work package is the local auditable execution unit.

Required fields:
- work package id
- title
- owner
- agent/human role
- related change intent
- affected surfaces
- status
- evidence required
- review checklist
- approval status
- merge/release note
- retrospective link

This is an execution-readiness scaffold only. It does not create worktrees, auto-merge, or orchestrate agents.
