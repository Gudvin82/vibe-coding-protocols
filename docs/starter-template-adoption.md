# Starter Adoption Matrix

Repository package: `v0.9.5`

VCP does not compete with starter templates. It controls projects built with them.

This matrix shows typical risks, recommended paths, first commands, PR Gate focus, proof artifacts, and dashboard sections for common project starting points.

## Included starter categories

- Bun / Hono / React / Astro starter
- Next.js / React SaaS starter
- Astro / marketing website starter
- Python backend / API project
- Brownfield monorepo
- Raw AI-generated MVP
- Spec-driven project
- Mobile / Expo app
- Internal tool / admin panel
- Public site / SEO-GEO surface

## Boundaries

No official integration is claimed with third-party starters. No logos are used.
