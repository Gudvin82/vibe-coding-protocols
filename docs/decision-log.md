# Decision Log

A VCP decision log is a project-governance record.

It is not a personal diary and not an AI personality memory layer.

## Recommended fields

- date;
- decision;
- alternatives;
- reason;
- risk;
- owner;
- status;
- follow-up;
- evidence or proof.

Use [templates/reports/decision-log.md](../templates/reports/decision-log.md) as a copyable structure.
