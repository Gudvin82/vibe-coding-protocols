# Product Spine

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

VCP product spine answers one question: what is the smallest honest control chain between AI output and a safe human decision.

VCP is not a hosted AI factory and not an autonomous release system.
It is a local-first control layer.

Canonical spine:

`Intent -> Route -> Work Package -> Gate -> Proof`

Expanded spine:

`Intake -> Charter -> Intent -> Route -> Plan -> Work Package -> Gate -> Proof -> Release Decision -> Maintain`
