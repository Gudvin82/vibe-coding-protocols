# Security Tooling Landscape

## VCP does

- security readiness workflows
- hardening routes
- review gates for meaningful AI-generated changes
- security baseline and incident templates
- third-party intake discipline
- route escalation into Hardening or Extended review

## VCP does not

- exploit scanning
- pentesting automation
- bug bounty automation
- red-team operations
- malware analysis
- DDoS, RAT or phishing tooling
- production security certification
- legal compliance certification
- external AI security review orchestration in this release

## External tools still needed

Use dedicated external tools for:
- SAST and DAST
- dependency scanning
- secret scanning
- SBOM and supply-chain tooling
- cloud posture checks
- manual security review
