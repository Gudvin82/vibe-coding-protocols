# Vibe Coding Protocols v0.6.1 — Foundation, Trust Gates, and AI Product Delivery

`v0.6.1` clarifies VCP as a foundation and trust layer for AI-assisted product delivery. It sharpens the README and docs around “build with AI, ship with control,” adds trust and PR gate workflows, score badges, review-diff planning, stronger VCP plus spec-first bridge guidance, flagship workflows, and case-study/adoption surfaces without turning VCP into a spec-kit clone.

## Added in `v0.6.1`

- product delivery lifecycle doc with minimum, full, and skip paths;
- flagship workflows doc with three public workflow narratives;
- `vcp review-diff` local pre-merge trust helper;
- `vcp score --badge` output modes;
- GitHub PR gate docs and reusable CI example;
- stronger spec-first bridge guidance;
- clearer platform status taxonomy;
- stronger anti-patterns and proof/case-study surfaces.

## What `v0.6.1` does not claim

`v0.6.1` does **not** claim:
- guaranteed production safety;
- official integrations where there are only docs or prompts;
- external certification through the score badge;
- GitHub Marketplace Action publication;
- broad external proof beyond the documented real, sanitized, synthetic, and template layers.
