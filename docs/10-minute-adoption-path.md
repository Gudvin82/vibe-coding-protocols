# 10-Minute Adoption Path

1. Run `python3 -m vcp_cli doctor --json`.
2. Run `python3 -m vcp_cli onboard --json`.
3. Run `python3 -m vcp_cli classify --json`.
4. Choose `brownfield-rescue`, `spec-foundation`, or `saas-ai-mvp-hardening`.
5. Preview adoption with `vcp adopt plan --json`.
6. Check release and PR Gate before merge.
