# Surface Priority Model

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

VCP surfaces are split into:
- required
- recommended
- optional
- advanced
- roadmap-only

Required:
- README / START_HERE
- trust-check
- control spine
- change intent
- PR Gate
- proof snapshot

Recommended:
- control catalog
- project control charter
- starter adoption matrix
- agent rule profiles
- flagship demo

Optional:
- dashboard artifact
- public proof demo
- case studies
- presentation assets
- integration packs

Advanced:
- evaluator receipt
- full benchmark run
- solo/squad path
- rule provenance
- deep hardening

Roadmap-only:
- hosted dashboard
- marketplace
- official VS Code extension
- cloud sync
- remote registry
- agent orchestration
