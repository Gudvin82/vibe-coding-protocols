# Technical Intake Workshop

Suggested duration: 1–2 hours.

Participants:
- tech lead
- senior developer
- product owner if available
- security/compliance representative if needed
- VCP facilitator

Sections:
- repo overview
- architecture surfaces
- AI usage
- critical flows
- risky files/modules
- tests and CI
- release flow
- desired pilot outcome

Outputs:
- intake summary
- risk map
- candidate track
- first audit backlog items
