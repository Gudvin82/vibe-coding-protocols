# AI-Augmented Solo/Squad Path

Repository package: `v0.9.0`

This guided path is for one human coordinating multiple AI agents or IDE copilots without losing control.

It is explicitly human-led. It does not claim autonomous orchestration.

## Flow

project-control-charter
→ change-intent
→ model routing
→ agent rule profile
→ work session
→ evaluation receipt / proof
→ PR Gate
→ trust-check

## Main risks

- conflicting edits
- duplicated work
- stale context
- overclaim
- unrun tests
