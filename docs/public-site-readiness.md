# Public Site Readiness

Use this route when publishing public docs,
marketing pages
or trust-sensitive AI-assisted products.

## Checklist

- canonical URLs
- readable docs index
- release links
- SECURITY and contact links
- license and contribution links
- sitemap plan
- robots plan
- `llms.txt`
- structured data that matches visible content
- honest limitations and what-this-is-not note
