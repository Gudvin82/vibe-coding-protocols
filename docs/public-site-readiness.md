# Public Site Readiness

Use this route when publishing public docs,
marketing pages,
or trust-sensitive AI-assisted products.

It focuses on publish safety, metadata honesty, and crawl readiness.
It does not guarantee indexing, ranking, or AI citations.

## Checklist

- canonical URLs
- readable docs index
- release links
- SECURITY and contact links
- license and contribution links
- sitemap plan
- robots plan
- `llms.txt`
- structured data that matches visible content
- honest limitations and what-this-is-not note

## When to use Public Site vs Public Growth

Use `public-site` when the main need is publishing readiness:
- docs navigation
- trust links
- crawl files
- release notes
- visible/schema alignment

Use `public-growth` when the main need is page strategy and discoverability structure:
- service page planning
- article/case/FAQ templates
- entity coverage
- GEO and AI visibility queries
- internal-link structure
