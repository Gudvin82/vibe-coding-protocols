# Vibe Coding Protocols v0.6.7 — Full Repo Intake and AI Audit Coverage

v0.6.7 adds a full repository intake protocol, mandatory AI audit coverage contract, machine-readable audit manifest, capability index and coverage report template so external AI agents can no longer present shallow WebFetch/README summaries as full VCP evaluations.

## Included in this release

- `FULL_REPO_INTAKE.md` as the short canonical intake contract for full VCP evaluation;
- `AI_FULL_REPO_AUDIT.md` as the evidence and disclosure contract for AI evaluators;
- `.vcp/ai-audit-manifest.json` as the machine-readable required inspection path;
- `REPO_CAPABILITIES_INDEX.md` as a compact capability-to-evidence map;
- `templates/reports/ai-repo-audit-coverage-report.md` for explicit coverage disclosure;
- local `vcp audit-plan` command for evaluation modes, required files, and failure contract;
- README, README_ru, AGENTS, TAKE_THIS_FIRST, AI intake, llms, index, catalog, cards, manifests, and benchmark sync for audit-coverage routing.

## Boundaries preserved

- no new methodology layer unrelated to intake and audit coverage;
- no weakening of the v0.6.7 two-track model;
- no claim that AI agents will always comply;
- no claim that WebFetch summaries equal full repository review;
- no fake metrics, copied frameworks, or overexpanded everything-framework scope;
- methodology version remains `v1.4` while repository package becomes `v0.6.7`.
