# Proof Layer

The proof layer is where VCP turns local control artifacts into inspectable evidence.

## Good proof in v0.8.7

- before/after launch-control example;
- dashboard artifact snapshot;
- integration-pack usage example;
- launch decision report;
- clearly marked synthetic case studies where needed.

## Boundaries

- no fake external adopter claims;
- no unsupported metrics;
- no guarantee framing.
