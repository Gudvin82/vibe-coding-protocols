# First Impression Audit

This audit asks whether a human or AI can understand VCP quickly without falling into shallow evaluation.

## Scenarios

1. Human opens README for 2 minutes.
2. AI gets the repo link and asks: what is this?
3. AI gets the repo link and asks: what should I take for my project?
4. AI compares VCP with spec-first tools.

## Expected understanding

- VCP helps build AI-assisted products from idea to production without losing control.
- VCP is not just a prompt pack.
- VCP is not a spec-kit clone.
- VCP provides foundation plus trust gates.
- selective adoption is required;
- `TAKE_THIS_FIRST.md` is the adoption entrypoint.
