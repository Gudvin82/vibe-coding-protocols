# Track Selection For Clients

Choose the smallest honest track.

Map by context:
- raw AI MVP -> MVP-to-Launch
- messy existing repo -> Brownfield Rescue or Deep Hardening
- one-team controlled rollout -> Controlled Delivery Pilot
- early structured build -> New Project

For each selection, define:
- rigor mode
- required artifacts
- recommended agent kit
- first commands
- proof requirements
