# Community and Adoption Status

Repository package: `v0.8.9`

VCP is still early. Stars and public community size are a limitation, but they are not the only maturity signal.

## Honest status

- the project is young;
- public adoption proof is still growing;
- low star count is a social-proof weakness, not by itself a proof of low technical value;
- maturity should be judged through proof surfaces, CLI behavior, tests, manifests, and release discipline.

## Evaluate by proof surfaces

Use:
- `docs/proof-snapshot.md`;
- `docs/benchmark-report.md`;
- `docs/trust-check.md`;
- `examples/public-proof/`;
- `case-studies/`.

## How to help

- star the repository;
- run `vcp trust-check --json`;
- open issues;
- submit an external evaluation receipt;
- share a case study;
- improve translations;
- test VCP with AI agents.

## Do not infer

- broad independent adoption that is not shown;
- guarantees from stars alone;
- ecosystem maturity from social proof only.
