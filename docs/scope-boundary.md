# Scope Boundary

<!-- vcp-version: v0.9.1 -->
<!-- methodology-version: v1.4 -->

VCP owns:
- control
- governance
- adoption
- proof
- evaluation
- PR/release gates
- local evidence

VCP does not own:
- app framework
- hosting
- deployment
- cloud orchestration
- IDE marketplace
- official plugin suite
- native IDE integration
- autonomous agent execution
- production certification
## v0.9.4 ecosystem boundary

- VCP does not ship external AI tools or models.
- It does not act as a model registry, crawler, or hosted discovery service.
- It does not certify legal, compliance, or vendor security status.
