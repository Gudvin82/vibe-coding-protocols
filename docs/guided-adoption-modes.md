
# Guided Adoption Modes

Choose the smallest mode that still gives you control.

## 5-minute
- read `START_HERE.md`;
- run `trust-check`;
- open route recommender;
- inspect flagship demo;
- choose the next path.

## 30-minute
- read product/control spine;
- run route recommendation;
- inspect scorecard and proof counts;
- choose one agent kit.

## Half-day
- build evidence bundle inputs;
- run trust-check, cards validate, benchmark run;
- inspect PR readiness and release decision matrix.

## Full audit
- open evaluator pack;
- inspect `.vcp/`, `vcp_cli/`, `tests/`;
- run the full repository evaluation path.
