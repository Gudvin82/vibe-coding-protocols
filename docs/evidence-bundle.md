
# Evidence Bundle

Evidence Bundle is a portable proof pack for review, PR handoff,
consulting, and release decisions.

Bundle contents:
- route recommendation;
- change intent;
- control charter;
- trust-check summary;
- evaluation receipt;
- proof counts;
- proof snapshot;
- benchmark references;
- PR gate;
- risk register;
- audit backlog summary;
- release decision;
- limitations;
- next actions.
