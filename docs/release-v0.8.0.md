# Vibe Coding Protocols v0.8.0 — Installable CLI, Safe Apply, and PR Gate Action

v0.8.0 makes VCP easier to adopt as a real tool: PyPI-ready packaging, tested local install paths, the `vcp` console command, safe non-destructive adoption apply, PR Gate GitHub Action templates, interactive workflow planning, and stronger Public Growth checks without overclaiming publication or automation guarantees.

## Included in this release

- installable Python package from a local clone;
- `vcp` console command after local install;
- PyPI-ready packaging surfaces and manual publication workflow scaffold;
- explicit safe `adopt apply` with target, confirm, dry-run, conflicts, and adoption log;
- PR Gate workflow template for GitHub Actions;
- safe interactive workflow preview mode;
- stronger Public Growth check/report output;
- VS Code extension kept as roadmap only.

## Boundaries preserved

- no public PyPI claim unless actually published;
- no public npm claim unless actually published;
- no destructive apply by default;
- no overwrite of existing files by default;
- no hidden workflow automation engine;
- no VS Code extension shipped in this release;
- no GEO/SEO ranking or citation guarantees.
