# Team Enablement Pack

Repository package: `v0.9.5`

This pack supports VCP-Pilot and VCP-Scale by turning key control surfaces into
a team training plan.

## Modules

1. VCP basics.
2. Route selection.
3. Agent kits.
4. Secure AI behavior.
5. PR readiness.
6. Evidence bundle.
7. Release decision.
8. Anti-chaos recovery.
9. Model/tool governance.
10. GitHub-native controls.

## For each module

Capture:
- target audience;
- duration;
- required reading;
- exercise;
- output artifact;
- success criteria.

## Why this matters

VCP-Pilot usually fails when only one maintainer understands the control layer.
This pack makes rollout teachable instead of purely tribal.
