# Ecosystem

VCP is not trying to replace every AI coding tool.

It can coexist with:

| Tool / pattern | What it is good for | How VCP relates |
|---|---|---|
| AGENTS.md | Project instructions for agents | VCP uses AGENTS.md as a copy-ready artifact |
| Claude Code / Codex / Cursor / Windsurf | AI coding IDEs | VCP provides rules, prompts, checks and workflow |
| Context7 / live docs MCP | Fresh library docs | VCP recommends live docs for third-party intake |
| Task Master / AI task managers | Task decomposition | VCP can feed tasks from `AUDIT_BACKLOG.md` |
| vibe-kanban / agent dashboards | Planning or review UI | VCP provides project artifacts and gates |
| Security scanners | Technical findings | VCP helps triage and route findings |
| Starter templates | Fast project bootstrap | VCP can wrap them with Product Brief, Architecture Map, AGENTS and Hardening |

## What VCP is

Agent harness and operating layer for AI-assisted delivery.

## What VCP is not

- not an awesome-list;
- not a package manager;
- not a runtime orchestrator;
- not a security scanner;
- not a replacement for tests or human review.
