# Comparison

This page is not a competitor takedown.
It is a simple positioning guide for what VCP tries to cover.

| Approach | Strength | Limitation |
|---|---|---|
| Cursor rules only | IDE-specific guidance | No audit, backlog or validation layer |
| `CLAUDE.md` only | Good Claude Code context | Not a full delivery workflow |
| Generic prompts | Fast start | No Memory Bank or review gates |
| Security scanner only | Finds technical issues | Does not structure AI delivery |
| Starter template | Fast bootstrap | Can lock you into a stack or deploy path |
| VCP | Agent harness, docs and checks | Requires adoption discipline |

## What VCP adds

VCP tries to connect:
- route selection;
- copy-ready templates;
- project memory;
- lightweight checks;
- audit backlog;
- release and incident documentation.

## What VCP does not claim

VCP does not claim:
- guaranteed security;
- automatic cost reduction;
- replacement of human review;
- proof of production readiness without project-specific work.
