# Spec Kit Bridge

VCP does not replace Spec Kit.
VCP can complement spec-first tooling with:
- AI intake
- adaptive spec depth
- hardening
- backlog linkage
- post-task review
- diagnostics
- operations
- public growth
- progressive disclosure

If you already use spec-first tooling, VCP can wrap it with governance and retrofit layers.
If you do not need full SDD, VCP can choose spec-lite or no-spec instead of forcing a large spec path.
