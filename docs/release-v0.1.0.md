# Vibe Coding Protocols v0.1.0 — Initial public toolkit

Initial public GitHub release of the Vibe Coding Protocols markdown toolkit.

This repository packages the public web methodology from:
[https://anmalishev.ru/expert/vibe-coding/](https://anmalishev.ru/expert/vibe-coding/)

- Web methodology version: `v1.4`
- Repository version: `v0.1.0`

## Included

- `protocols/`
  - Hub
  - Starter Protocol
  - Hardening Protocol
  - Starter to Hardening bridge
  - AI IDE compatibility
- `prompts/`
  - master prompts
  - Product Brief prompt
  - Starter prompts
  - Hardening prompts
  - Independent diff review prompt
  - Stack decision matrix prompt
- `templates/`
  - `AUDIT_BACKLOG.md`
  - `AGENTS.md`
  - `PROJECT_MAP.md`
  - `ARCHITECTURE_SOURCE_OF_TRUTH.md`
  - `SECURITY_SCANNER_REPORT.md`
  - `LEGAL_CHECKLIST.md`
  - `PAYMENT_FISCALIZATION_CHECKLIST.md`
- `agents/`
  - examples for Claude Code, Codex, Cursor and Windsurf
- `checklists/`
  - self-protection
  - safe integration
  - database/load/scalability
  - device/browser QA
  - migration rollback
  - AI-generated test strategy
- `examples/`
  - synthetic walkthroughs for starter, light hardening and full hardening routes
- `scripts/` and `.github/workflows/`
  - lightweight toolkit validation helpers

## Disclaimer

This toolkit is not a guarantee of security, not a pentest, not legal advice and not a replacement for human review.
