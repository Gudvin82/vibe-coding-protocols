# Product Model

Repository package: `v0.9.5`

Use this mental model to understand VCP quickly.

## Core

Required control-layer surfaces:
- version surfaces;
- CLI;
- track model;
- adopt plan;
- safe apply dry-run;
- release-check;
- PR Gate model;
- cards/index validation;
- trust-check.

## Guided Paths

User-facing flows:
- 10-minute adoption path;
- MVP-to-Launch Path;
- spec-driven adoption path;
- local platform flow;
- contracts-first AI-MVP demo;
- SaaS AI-MVP hardening.

## Optional Layers

Useful but not required:
- local dashboard artifact;
- project memory;
- audit backlog;
- run state/checkpoints;
- integration packs;
- agent instruction templates;
- docs-site scaffold;
- batch evaluation.

## Roadmap-only

Not shipped:
- hosted dashboard;
- VS Code extension;
- plugin marketplace;
- Go rewrite;
- public PyPI/npm publication;
- remote plugin registry;
- cloud sync.

## Why this model matters

This keeps VCP understandable:
- Core explains what the toolkit really is.
- Guided Paths explain how to use it.
- Optional Layers explain what can be added later.
- Roadmap-only explains what should not be overclaimed.
