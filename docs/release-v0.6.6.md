# Vibe Coding Protocols v0.6.6 — New Project Foundation and Existing Project Control

v0.6.6 strengthens VCP's two core tracks: building new AI-assisted products from idea to controlled implementation, and bringing existing AI-generated projects under governance, hardening, review gates, and release readiness.

## Included in this release

- clear two-track model: New Project Track and Existing Project Track;
- Spec Foundation docs and protocol;
- Spec Quality Gate docs, report, prompt, benchmark, and lightweight CLI helper;
- new-project walkthrough from idea to controlled foundation;
- AI MVP hardening walkthrough for existing repositories;
- release-readiness and architecture-drift control surfaces;
- Brownfield Rescue Pack for existing repositories with visible control debt;
- stronger PR Gate decision model and CI example updates;
- synced cards, index, catalog, manifests, reports, benchmarks, README, README_ru, and AI evaluation routing.

## Boundaries preserved

- no new everything-framework direction;
- no vendoring or copying of external spec-first tooling;
- no official integration claim where none exists;
- no production safety or release guarantee claim;
- methodology version remains `v1.4` while repository package becomes `v0.6.6`.
