# Ecosystem Map

Repository package: `v0.9.0`

VCP belongs to the local AI control layer of the ecosystem.

| Category | Main role | VCP relationship |
| --- | --- | --- |
| Spec Kit | Define what to build | Complementary |
| OpenSpec-like tools | Track spec delta and brownfield evolution | Complementary |
| Full-stack templates | Bootstrap where to build | Complementary |
| Agent rules repos | Instruct how agents behave | Complementary |
| Agent toolkits | Execute and automate | Complementary |
| VCP | Control, verify, and accept what AI produced | Local-first control layer |

Spec tools define what to build.
Templates bootstrap where to build.
Agent tools execute and automate.
Rule repos instruct how agents behave.
VCP controls, verifies, and accepts what AI produced.

VCP complements adjacent tools and does not replace them.
