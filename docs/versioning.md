# Versioning

This project uses two version lines:

- Repository package `v0.5.1` — GitHub toolkit packaging, CLI, manifests, benchmarks, examples, CI and docs.
- Web methodology `v1.4` — public methodology pages on `anmalishev.ru`.

Repository package versions track the GitHub-distributed framework.
Methodology version tracks the public web methodology.

Current repository package: `v0.5.1`.
Current web methodology: `v1.4`.

`v0.5.1` adds Windows-first Python CLI parity for core workflows and a first-class Third-party API Intake discipline with registry, review and benchmark coverage.
These surfaces are real and locally executable, but they still do not imply native installer distribution, automatic terms review, vendor risk automation or security certification.
