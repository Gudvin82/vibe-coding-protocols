# Versioning

This project uses two version lines:

- Repository package `v0.5.0` — GitHub toolkit packaging, CLI, manifests, benchmarks, examples, CI and docs.
- Web methodology `v1.4` — public methodology pages on `anmalishev.ru`.

Repository package versions track the GitHub-distributed framework.
Methodology version tracks the public web methodology.

Current repository package: `v0.5.0`.
Current web methodology: `v1.4`.

`v0.5.0` adds a product-grade local CLI surface, machine-readable manifests, benchmark scenarios, demo docs and stronger adoption/review wiring.
These surfaces are real and locally executable, but they still do not imply mature IDE plugins, hosted docs publishing, external AI orchestration or security certification.
