# Versioning

This project uses two version lines:

- Repository package `v0.5.5` — GitHub toolkit packaging, CLI, npm wrapper, manifests, benchmarks, examples, CI and docs.
- Web methodology `v1.4` — public methodology pages on `anmalishev.ru`.

Repository package versions track the GitHub-distributed framework.
Methodology version tracks the public web methodology.

Current repository package: `v0.5.5`.
Current web methodology: `v1.4`.

`v0.5.5` improves AI evaluation accuracy and npm entrypoint readiness.
It adds a repository evaluation guide,
a dedicated `vcp evaluate` helper,
clearer scoring semantics,
and honest public-proof positioning without faking distribution maturity.
