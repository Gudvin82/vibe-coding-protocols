# Versioning

This project uses two version lines:

- Repository package `v0.5.8` — GitHub toolkit packaging, CLI, npm wrapper, manifests, cards, benchmarks, examples, CI and docs.
- Web methodology `v1.4` — public methodology pages on `anmalishev.ru`.

Repository package versions track the GitHub-distributed framework.
Methodology version tracks the public web methodology.

Current repository package: `v0.5.8`.
Current web methodology: `v1.4`.

`v0.5.8` adds progressive-disclosure discovery, `.vcp/index.json`, VCP Cards, platform compatibility docs, CLI index/cards commands, and stronger AI-native inspection guidance for large repositories.
