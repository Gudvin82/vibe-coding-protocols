# Versioning

This project uses two version lines:

- Repository package `v0.5.3` — GitHub toolkit packaging, CLI, npm wrapper, manifests, benchmarks, examples, CI and docs.
- Web methodology `v1.4` — public methodology pages on `anmalishev.ru`.

Repository package versions track the GitHub-distributed framework.
Methodology version tracks the public web methodology.

Current repository package: `v0.5.3`.
Current web methodology: `v1.4`.

`v0.5.3` adds an operations feedback loop and a project kanban backlog workflow.
It keeps the existing local Python CLI and Bash checks,
adds read-only production error capture and daily triage guidance,
and separates ongoing project work from hardening findings by introducing `PROJECT_BACKLOG.md` next to `AUDIT_BACKLOG.md`.
