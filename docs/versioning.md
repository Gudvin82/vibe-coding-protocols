# Versioning

This project uses two version lines:

- Repository package `v0.6.0` — GitHub toolkit packaging, CLI, npm wrapper, manifests, cards, benchmarks, examples, CI and docs.
- Web methodology `v1.4` — public methodology pages on `anmalishev.ru`.

Repository package versions track the GitHub-distributed framework.
Methodology version tracks the public web methodology.

Current repository package: `v0.6.0`.
Current web methodology: `v1.4`.

`v0.6.0` adds a spec-first lane, workflow catalog, diagnostics layer, catalog filters over VCP Cards, and a normalized event schema for findings and release-gate records.
