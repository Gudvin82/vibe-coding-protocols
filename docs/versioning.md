# Versioning

This project uses two version lines:

- Repository package `v0.5.4` — GitHub toolkit packaging, CLI, npm wrapper, manifests, benchmarks, examples, CI and docs.
- Web methodology `v1.4` — public methodology pages on `anmalishev.ru`.

Repository package versions track the GitHub-distributed framework.
Methodology version tracks the public web methodology.

Current repository package: `v0.5.4`.
Current web methodology: `v1.4`.

`v0.5.4` turns the backlog layer into a practical working control surface.
It keeps the existing local CLI and operations route,
adds safer backlog state changes and reporting,
links backlog work to architecture memory updates,
and keeps delivery tracking separate from `AUDIT_BACKLOG.md`.
