# Versioning

## Web version vs repository version

У сайта и репозитория разные version tracks.

- Web methodology currently mirrors `Vibe Coding Protocols v1.4`.
- Repository starts with `v0.1.0`.

Это сделано специально:
- сайт — живая публичная витрина;
- GitHub repo — markdown toolkit и open-source distribution format.

## Prompt versioning inside real projects

Если проект ведется через AI, полезно сохранять адаптированные prompt-блоки в `docs/PROMPTS.md`.

Минимум:
- дата;
- версия протокола;
- какой prompt использовался;
- какой был результат;
- какие файлы были изменены;
- какие риски остались.
