# Docs-site Scaffold

`docs-site/` is an optional documentation scaffold.

It is not required for the Python CLI.
It does not claim a hosted docs deployment.
It does not add npm dependencies in this release.

Recommended structure:
- start here
- 10-minute path
- track model
- MVP-to-Launch
- local platform flow
- dashboard
- integration packs
- PR Gate
- project memory
- audit backlog
- agent control
- proof layer
- Russian docs links
