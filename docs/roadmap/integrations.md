# Integrations Roadmap

Use [docs/integrations/status-model.md](../integrations/status-model.md) and [.vcp/integrations.json](../../.vcp/integrations.json) as the source of truth for current status.

## Current boundaries

- shipped: local CLI, local dashboard artifact, metrics board, integrations list command;
- local-template: starter control layer, PR Gate workflow template;
- experimental: plugin contract draft, docs-site scaffold;
- roadmap: VS Code extension, future public publication paths;
- not-shipped: hosted dashboard, plugin marketplace, Go rewrite, web control plane.
