# Integration Roadmap

This page describes future-facing integration directions for VCP.
It does not claim that these integrations are already shipped.

## Current state

Today VCP ships:
- a local Python CLI;
- an installed `vcp` console command after local install;
- a local npm wrapper;
- GitHub workflow templates such as PR Gate examples;
- roadmap docs for future product surfaces.

## Roadmap-only surfaces

These are roadmap or architecture directions unless separately implemented and released:
- VS Code extension;
- dashboard or hosted control plane;
- plugin marketplace;
- alternative CLI runtimes or rewrites;
- broader integration engine abstractions.

## Honesty rules

Do not claim:
- official VS Code extension availability;
- public PyPI or npm publication unless actually published;
- hosted dashboard availability unless implemented;
- official marketplace integrations unless published as such.

## How to describe integrations safely

Say:
- documented roadmap;
- template/workflow path;
- local installable CLI;
- future architecture direction.

Do not say:
- shipped extension;
- official integration;
- public package availability;
- managed platform guarantee.
