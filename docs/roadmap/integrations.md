# Integrations Roadmap

Use [docs/integrations/status-model.md](../integrations/status-model.md), [docs/integration-packs.md](../integration-packs.md), [.vcp/integrations.json](../../.vcp/integrations.json), and `.vcp/integration-packs.json` as the source of truth for current status.

## Current boundaries

- shipped: local CLI, local dashboard artifact, metrics board, integrations list command, integration packs registry view;
- local-template: starter control layer, PR Gate workflow template, contracts-first path, PyPI readiness pack;
- experimental: plugin contract draft, docs-site scaffold;
- roadmap: VS Code extension, future IDE UX, future public publication paths;
- not-shipped: hosted dashboard, plugin marketplace, Go rewrite, web control plane.

## Future IDE UX (roadmap only)

- route panel;
- MVP-to-Launch checklist;
- dashboard preview;
- PR Gate status;
- project memory/backlog view;
- agent instruction template helper;
- integration status view;
- launch decision checklist.
