# External Evaluation

Repository package: `v0.9.5`

Use `templates/reports/external-evaluation.md` when you want a fair, bounded external review of VCP.

The evaluator should record:
- who or what performed the review;
- which files and URLs were inspected;
- whether commands were actually run;
- what category VCP was compared in;
- what is shipped versus optional versus roadmap-only.

Do not call the evaluation full if `.vcp/`, `vcp_cli/`, `tests/`, and `docs/benchmark-report.md` were skipped.
