# Diagnostics

Repository package: `v0.9.5`

`doctor` checks the local toolkit environment.

`diagnose` checks project/process readiness by layer:
- repository state
- route and intake discipline
- architecture memory
- backlog and audit trail
- spec lane
- review and release gates
- manifests, cards, workflows, benchmarks
- public-growth and operations layers when relevant

Diagnostics are local-only and do not access production systems or external networks.
