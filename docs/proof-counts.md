
# Proof Counts

`v0.9.3` introduces a canonical proof-count snapshot.

When counts differ, `.vcp/proof-counts.json` is the canonical counted
snapshot for the release.

Use it for README, proof snapshot, evaluator pack, and release notes.

## Included counts

- repository package version;
- benchmark scenarios;
- cards;
- CLI commands in manifest;
- tests;
- report templates;
- diagrams;
- agent kits;
- client adoption templates;
- release docs;
- docs_ru surfaces.
