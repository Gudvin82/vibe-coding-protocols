# Code of Conduct

## Our standard

Давайте держать репозиторий профессиональным, спокойным и полезным.

Ожидаемое поведение:
- уважение к другим участникам;
- критика идей, а не людей;
- аккуратная работа с security / privacy темами;
- честное attribution сторонних идей.

Неприемлемо:
- harassment;
- doxxing;
- публикация secrets или private project data;
- токсичное поведение и личные атаки.
