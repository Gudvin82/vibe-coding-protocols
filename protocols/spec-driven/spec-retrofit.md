# Spec Retrofit

Use this lane when code exists but specs do not.

## Workflow

1. Inspect available docs.
2. Inspect project memory and architecture notes if present.
3. Capture observed behavior.
4. Write `OBSERVED_SPEC.md`.
5. Write `SPEC_GAPS.md`.
6. Propose acceptance criteria.
7. Add backlog follow-up.
8. Do not rewrite code in this lane.
