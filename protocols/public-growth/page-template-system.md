# Page Template System

Use the template system to keep public pages consistent in intent, funnel stage, structure, internal links, and schema recommendations.

## Template families

- homepage;
- service or product page;
- article;
- case study;
- FAQ page;
- comparison page;
- alternatives page.

Each template should define:
- target search intent;
- funnel stage;
- AI-answer friendly summary;
- internal links;
- schema suggestions;
- CTA;
- update cadence.

## Why this exists

Teams often create public pages one-off.
The template system keeps structure and discoverability consistent without pretending every site needs the same marketing stack.
